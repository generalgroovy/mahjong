Decision trees

Expandable game-theory trees for discard, riichi, call, push/fold, and kan decisions.

Information-set tree
Information set It observed public state + your private hand + beliefs over hidden tiles.
Public state discards, calls, dora indicators, riichi declarations, honba, sticks, scores, dealer, round.
Private state your tiles, shanten, ukeire, yaku routes, value distribution, safe tiles.
Belief state opponent hand ranges, wall composition, dead-wall unknowns, tenpai probability, wait/value distributions.
Legal actions win, riichi, discard, chi, pon, kan, pass, fold line.
Discard tree 
DISCARD NODE
1. Can you legally win?
   ├─ Yes: win unless placement demands refusal.
   └─ No: continue.
2. Is any opponent in high-threat state?
   ├─ Yes: enter push/fold tree.
   └─ No: continue offense tree.
3. For each discard candidate:
   ├─ Resulting shanten
   ├─ Live ukeire
   ├─ Wait quality
   ├─ Yaku and dora retention
   ├─ Expected hand value
   ├─ Immediate discard safety
   ├─ Future draw safety
   └─ Callability / openness cost
4. Select max: offensive EV + rank EV − deal-in risk − flexibility loss.
Riichi tree 
RIICHI NODE
Closed tenpai?
├─ No: cannot riichi.
└─ Yes:
   ├─ Dama hand already high value?
   │  ├─ Yes: compare dama EV vs riichi EV.
   │  └─ No: riichi value premium rises.
   ├─ Wait quality?
   │  ├─ Ryanmen / multi-sided: riichi usually favored.
   │  ├─ Bad wait + high value: mixed.
   │  └─ Bad wait + cheap + dangerous: dama/fold often better.
   ├─ Opponent state?
   │  ├─ No threat: riichi pressure valuable.
   │  ├─ One threat: require good wait/value.
   │  └─ Multiple threats: riichi only with strong need.
   └─ Rank context?
      ├─ Need points: riichi more attractive.
      ├─ Leading all-last: dama/fold more attractive.
      └─ Dealer/honba/sticks: riichi EV rises.
Call tree 
CALL NODE
Opponent discards callable tile.
├─ Does call complete winning hand?
│  └─ Ron if legal and rank-correct.
├─ Does call reduce shanten?
│  ├─ No: usually pass.
│  └─ Yes: continue.
├─ Is there a valid yaku route after call?
│  ├─ No: usually pass.
│  └─ Yes: continue.
├─ Value after call?
│  ├─ 1000–2000: call only for speed/rank/dealer need.
│  ├─ 3900+: call often viable.
│  └─ Mangan+: call strongly if speed improves.
└─ Defense cost?
   ├─ High: pass.
   └─ Low: call if EV-positive.
Push/fold tree 
PUSH/FOLD NODE
Opponent threat detected.
├─ Are you tenpai?
│  ├─ No:
│  │  ├─ 2+ shanten: fold unless very high value/rank-forced.
│  │  └─ 1 shanten: push only with value + ukeire + safe path.
│  └─ Yes:
│     ├─ Good wait + good value: push more.
│     ├─ Bad wait + cheap hand: fold/dama more.
│     └─ Dealer/all-last need: rank-adjust.
└─ Discard safety order:
   1. Genbutsu against all threats
   2. Completely safe honor/no-chance tiles
   3. Genbutsu against most dangerous opponent
   4. Suji terminals
   5. Suji 2/8
   6. Suji 3/7
   7. One-chance / kabe-informed tiles
   8. Raw middle tiles 4/5/6 last
Kan tree 
KAN NODE
Can declare kan?
├─ No: continue.
└─ Yes:
   ├─ Opponents in riichi / high threat?
   │  ├─ Yes: avoid unless win/EV/rank strongly requires.
   │  └─ No: continue.
   ├─ Does kan improve your hand?
   │  ├─ Replacement draw / extra dora / preserves tenpai: consider.
   │  ├─ Breaks shape or safety: avoid.
   │  └─ Adds value to strong dealer/tenpai hand: consider.
   └─ After riichi?
      └─ Only under strict concealed-kan restrictions.

Near-GTO policy matrix

Action-level heuristics organized by phase, threat, and hand state.

Early game

  • Choose lowest shanten, then highest live ukeire.
  • Keep dora and yaku if the efficiency cost is small.
  • Prefer flexible middle tiles over isolated terminals.
  • Do not open without a valid yaku route.
  • Keep a safe tile when the hand is slow.

Midgame

  • Fast cheap hands are valid when stopping dealer or improving placement.
  • Slow cheap hands should convert to defense.
  • Strong 1-shanten hands can push through moderate threat.
  • Visible open mangan threats should be treated as riichi-equivalent.
  • Dealer pressure increases folding threshold.

Endgame

  • Tenpai near exhaustive draw can justify safe pushes.
  • Noten + unsafe tiles usually folds.
  • All-last leader maximizes placement, not raw points.
  • Exact point requirements determine dama/riichi/yaku choices.
  • Dealer continuation value can justify extra risk.

Solver architecture

A static site cannot run full self-play RL, but this architecture shows how to extend the model into a real engine.

Core action scorer

EV(a|s) = PwVw + PtVt − PdLd − PoLo − C(a) + Rrank
  1. Enumerate legal actions.
  2. Compute resulting shanten and live ukeire.
  3. Estimate hand-value distribution.
  4. Estimate opponent tenpai/value/wait distributions.
  5. Estimate deal-in risk by discard.
  6. Apply rank utility.
  7. Choose max-EV action.
